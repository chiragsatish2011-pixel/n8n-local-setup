STEP 2 OF 5 · COMPULSORY

Verify + Allow scripts

Confirm the install, then give the one-time permission npm needs. Without it, npm -v fails on most PCs.

Windows PowerShell
node -v
v24.20.0
npm -v
12.0.2
  • 1Press Win + X
  • 2Choose PowerShell
  • 3Type node -v → Enter
  • 4Type npm -v → Enter
See "not recognized"?

Close PowerShell, reopen it, try again — Windows needs a fresh window sometimes.

Windows PowerShell (Administrator) — compulsory
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Execution Policy Change
Do you want to change the execution policy?
[Y] Yes [N] No [S] Suspend (default is "N"): Y
Why

Windows blocks scripts by default. This unlocks npm's tools safely — one time only.

How

Right-click PowerShell → Run as administrator first. Type Y, hit Enter.

Restart & double-check

The real test — does it survive a reboot?

  • 1Press Ctrl + C in n8n's window
  • 2Close PowerShell completely
  • 3Reopen PowerShell
  • 4Type the same launch command
  • 5Open localhost:5678 again
Success looks like

The same message every time. No red error text.

Connecting Google apps to n8n

Let n8n read Gmail, edit Sheets, manage Calendar. Six steps, once per project. Open Console

1
STEP 1 OF 6

Create your Cloud project

Free. Stays free for local n8n use.

  • 1Go to console.cloud.google.com
  • 2Sign in with any Google account (or sign up free)
  • 3If Google asks for money or card — SKIP it. Erase that page. Just open console.cloud.google.com. Home n8n needs NO billing.
  • 4Click project dropdown (top bar) → New Project
  • 5Name it → Create → wait 10 sec → click it
No payment needed

If you see “billing” or “free trial”, close it. A free project is enough for this whole guide.

See "Access blocked"?

Google needs 2-step verification on your account first. Turn it ON in the band above, then refresh. One-time, per account.

2
STEP 2 OF 6

Enable the Google APIs

Once per app, per project. Enable ALL the apps n8n will use — do them one by one, same way every time.

  • 1☰ menu → APIs & Services → Library
  • 2Search the API name in the top search box
  • 3Click result → Enable (blue button)
  • 4Back to Library → repeat for each app below
✉️
Gmail API → EnableRead, send & label
▦
Sheets API → EnableRead/write rows
▲
Drive API → EnableUpload & manage files
31
Calendar API → EnableCreate & update events
3
STEP 3 OF 6

Set up the consent screen

Google needs to know your app's name.

  • 1Sidebar → OAuth consent screen
  • 2App name — anything, e.g. "My n8n Automations"
  • 3Pick your support email
  • 4Next → Next → choose External → Finish
4
STEP 4 OF 6

Add yourself as a test user

Required while your app is in "Testing" mode.

OAuth consent → Audience
Publishing status
Testing
Test users
+ ADD USERS
you@gmail.com
  • 1Consent screen → Audience tab
  • 2Find Test users → "+ Add users"
  • 3Type the Gmail you'll use in n8n
  • 4Save
Don't skip this

Skip it, and n8n's Google sign-in shows "Access blocked" later.

5
STEP 5 OF 6

Create OAuth credentials

This generates your Client ID & Secret — the same pair you will reuse in every Google node.

  • 1Click "Get started" to finish setup
  • 2Sidebar → Credentials
  • 3"+ Create Credentials"
  • 4Choose OAuth client ID
  • 5Application type → Web application
One more field

Under "Authorized redirect URIs," paste the exact URL n8n shows you — get it from inside an n8n Google node's credential box first.

Where to find the redirect URL — in n8n
Open n8n → add a Google node → "Connect to Gmail"
http://localhost:5678/rest/oauth2-credential/callback
# copy this exact URL into Google Cloud Console
6
STEP 6 OF 6

Save your credentials

You'll reuse this pair everywhere. Save it now — example: you set up Gmail today, tomorrow a Sheets node asks to connect → paste the SAME Client ID + Secret there.

After clicking Create

Google shows your Client ID & Client Secret. Copy both into a notes app or password manager now — the Secret may need regenerating if lost. You will paste this same pair into Gmail, Sheets, Drive, Calendar — every Google node.

  • 1Add a Gmail node → "Connect to Gmail"
  • 2Paste Client ID
  • 3Paste Client Secret
  • 4Sign in with Google → approve

🔁 Same Client ID & Secret go into every Google node — Sheets, Gmail, Drive, Calendar…
